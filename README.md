# Story 12 Levels: a storytelling skill for Claude

Vinay Chahal's system for writing video scripts that people actually watch. Once installed, Claude uses it automatically whenever it writes or reviews a script, Short, Reel, long-form video, ad or hook.

What it does: an idea test before any script, crazy-simple one-idea drafting, a shots-first table, 15 tested hooks, and a 12-level X-ray with a scorecard pasted under every script.

## Install in Claude Code

```
/plugin marketplace add Chahaliop/story-12-levels
/plugin install story-12-levels@vinay-storytelling
```

## Install in the Claude app (claude.ai)

Download `story-12-levels.zip`, then go to Settings → Capabilities → Skills → Upload skill.
